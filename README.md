# Expense Tracker (web app)

Built web version of the Expense Tracker, published with GitHub Pages at
https://digitalhomeacc-jpg.github.io/expense-tracker/

On iPhone: open the link in Safari → Share → **Add to Home Screen**.

Source code: `expense_tracker/` in the dukaan-khata repository. This repo only holds the built files,
so don't edit them by hand – rebuild instead.
